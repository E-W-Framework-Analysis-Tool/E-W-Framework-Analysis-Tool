# Dev Utilities Browser-based Project

This project contains browser-based developer utilities for maintaining
this codebase. This includes a UI for managing framework reference metadata
and a view that shows a potentially cleaner diff of framework resources
compared to a traditional Git text-based diff.

This project is to be considered "as-is" quality. It is a rough sketch of
tools used for a particular purpose, and will likely not be maintained for
some time. Nonetheless, the tools within may prove to be a useful starting
point for updates in the future and so are included here.
